# Seguridad y privacidad

## Alcance

La aplicación procesa documentos judiciales potencialmente sensibles. El diseño evita subir PDFs o datos de casos a un backend: extracción, OCR, revisión y cálculo se ejecutan en el navegador.

## Uso seguro

- Use equipos y perfiles de navegador autorizados.
- Trate los archivos de sesión JSON y las exportaciones CSV como información sensible.
- No adjunte PDFs ni datos reales en issues públicos.
- Verifique el origen de la aplicación antes de cargar documentación.

## Reporte de vulnerabilidades

Reporte una vulnerabilidad mediante un **GitHub Security Advisory privado** del repositorio. No incluya documentación judicial real; use ejemplos sintéticos mínimos que permitan reproducir el problema.
